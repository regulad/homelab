# aboriginal: Nextcloud fetches from LAN addresses, through a config file host_files writes (2026-11-05)

- News's four RSSHub feeds had failed since 2026-10-28, each with "Local server access is not allowed": on the LAN, rsshub.regulad.xyz resolves to ingress's 10.23.2.31, and Nextcloud refuses private addresses unless `allow_local_remote_servers` is true. Only a signed-in user can have Nextcloud fetch a URL, so the setting is on.
- Nextcloud merges every `*.config.php` in its config directory over `config.php`. `host_files` writes `/opt/nextcloud/homelab.config.php`, and the compose file binds it read-only into the `config` volume's directory, so the settings this repository owns live beside the `config.php` Nextcloud writes. `occ config:system:get` reads the merged value.
