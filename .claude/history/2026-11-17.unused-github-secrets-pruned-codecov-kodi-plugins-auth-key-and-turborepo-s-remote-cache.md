# Unused GitHub secrets pruned: Codecov, kodi-plugins' auth key, and Turborepo's remote cache (2026-11-17)

- **The check:** a secret is unused when no file under `.github/workflows/` or `.github/actions/`, nor any `action.yml`, on the repository's default branch names it as `secrets.<NAME>`, and no workflow passes `secrets: inherit` or reads `secrets[...]`. Dependabot secrets count by the same names.
  - Some repositories default to a branch other than `main` (nssm and redroid-script use `ci`), so the default branch is read from the API.
- **zsh:** it does not split unquoted variables on whitespace, so `for f in $files` there sees one word. Run such loops under `sh`, or the per-repository result is silently wrong.
- **Turborepo:** doppelganger's `TURBO_TOKEN` and `TURBO_TEAM` (`nefum`) had never worked; each run's remote cache answered 403, and turbo fell back to the `.turbo/cache` that `actions/cache` restores. doppelganger dropped them (its ccceb16), then the secret and the repository variable were deleted.
- **Also deleted:** PepperCord's `CODECOV_TOKEN`, unreferenced, and kodi-plugins' `TS_AUTHKEY` with its `ci-kodi` auth key, which kodi-plugins' federated identity replaced. A revoked Tailscale key still answers `GET` with `revoked` set and `invalid: true`.
