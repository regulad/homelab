# mail's docker-mailserver configuration is imported as it was (2026-11-04)

- The 19 files docker-mailserver reads from the host are in `files/mail/root/mailserver/`, at the paths its compose project binds, owned and moded as they were. A check against mail found nothing to change. The configuration still points LDAP at the old realm, `ldaps://freeipa.regulad-verizon-livingston.internal` with base `dc=home,dc=arpa`, which answers through the `ldap_proxy`; moving it to `wako.regulad.internal` is left for later.
- Files holding secrets are templates, or content from mail's `secrets.sops.yml`: `LDAP_BIND_PW` and `SRS_SECRET` in `mailserver.env`; `postfix-sasl-password.cf`, the logins for OCI Email Delivery and Gmail; the two DKIM private keys; and Spamhaus's DQS key, which `rspamd-dqs/rbl.conf` repeats in 12 query names. `postfix-sasl-password.cf` holds no "password" word, and only checking each file's shape found it.
- `mailserver.env` is upstream's template, with 111 settings among 550 lines of comments. Its commented-out `RELAY_HOST`, `RELAY_PORT`, `RELAY_USER` and `RELAY_PASSWORD` still carried a retired relay's values; they are blanked. A search for `KEY=value` in comments also turns up upstream's documentation lines, such as `# empty => …`, which carry no values.
- `fail2ban-jail.cf`'s `ignoreip` held the pubsub subnet's GUA `/64`. In the template it is `(ipv6_address ~ '/64') | ip_network`, from the instance's address in OpenTofu's state, through `host_files`' own filter. The `ipv6subnet_cidr` beside the address in the instance's state is empty.
- community.sops' vars plugin, and `community.sops.load_vars`, strip the whole decrypted document, so when the last value in a SOPS YAML file is a multi-line `|` block, Ansible loads it without its final newline: <https://github.com/ansible-collections/community.sops/issues/309>. `sops decrypt --extract` returns the value whole. A DKIM private key and doppelgangerhq.com's `cron.env` were affected. Until #309 is fixed, each SOPS vars file ends with a one-line value: mail's with `mailserver_spamhaus_dqs_key`, doppelgangerhq.com's with `docker_ghcr_token`. The lookup plugin has had an `rstrip` option since #61.
