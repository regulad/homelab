# bot@regulad.net is regubot's mailbox, a FreeIPA account that only receives (2026-11-23)

- **What makes a mailbox:** a FreeIPA account in wako's `freeipa_users_public`. mail's `ldap-aliases.cf` maps every address an account holds to `<uid>@regulad.xyz`, which Postfix hands to Dovecot's LMTP, and Dovecot finds the user by uid. So the account `regubot` receives at `bot@regulad.net` without holding `regubot@regulad.xyz`, and its owner reads it by logging in as `regubot@regulad.xyz`. Without that address in its list, Postfix's login map lets it send as no address.
- **Its password:** `freeipa_users_private` merges into the public list by name, so a generated password for an account listed in public goes in the private list as an entry of its own, `{name, password}`, beside the account's private addresses. No lookup into another file is needed, as `svc-doppelganger-supabase`'s into `tofu/supabase` is.
- **Generating into SOPS:** `sops edit` with `EDITOR` set to a script appends the generated value, with its provenance comment, to the decrypted temporary file, so the value never reaches a terminal or a file of the session's. SOPS keeps a comment inside a list item's mapping, encrypted as a `#ENC[…]` line above the key.
- **Email Delivery:** `tofu/oracle/bin/email-senders` takes in every address of the declared accounts, and as regulad.net is an Email Delivery domain, `tofu/oracle` approves `bot@regulad.net` as a sender, though the account cannot send through mail.
- **Delivery, tested from Gmail:** Postfix's LMTP line for the message reads `to=<regubot@regulad.xyz>, orig_to=<bot@regulad.net>, … status=sent (250 2.0.0 <regubot@regulad.xyz> … Saved)`. The `Saved` is Dovecot's reply; mail's `/var/log/mail/mail.log` has no Dovecot `saved mail to INBOX` line to look for instead.
- **From a worktree:** `ansible-generated`'s gonkputer inventory source runs `bin/tofu-gonkputer`, which reads `tofu/gonkputer/secrets.auto.tfvars.json`; without it the source fails as "Unexpected AnsibleError", so run `sh tofu/gonkputer/prepare.sh` in the worktree first. A container's connection through `proxmox_pct_remote` waits on the agent's signature for prodingus, and a prompt left unanswered fails the host as `UNREACHABLE` with "Authentication timeout".
