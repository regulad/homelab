# The LAN pulls Docker Hub and ghcr.io through Nexus, at docker-cr and ghcr-cr.regulad.xyz (2026-11-18)

- **Docker's API needs a host's root:** a Docker or Podman client always requests `<host>/v2/<name>/…`. A Podman mirror location may carry a namespace (`[[registry.mirror]] location = "host/ns"`), but the namespace becomes part of the repository name after `/v2/`, never a path before it. So Nexus's `/repository/<name>/v2/` is out of a client's reach, and each Docker repository needs a host of its own whose `/v2/` Caddy rewrites to it, as `cr.regulad.xyz` always had. Docker's own `registry-mirrors` mirrors Docker Hub alone.
- **Path-based routing was not used:** since 3.83, Nexus can serve a Docker repository at `/v2/<repository>/…` on its own root, a per-repository setting (`docker.pathEnabled`). But Sonatype's Docker page says "Using a mix of docker repository routing types at the same time is not supported", and doesn't say whether `/repository/<name>/v2/`, which `cr.regulad.xyz` relies on, keeps working beside it. Parker kept Nexus's settings as they were.
- **One snippet, three hosts:** the Caddyfile's `(nexus_docker)` snippet holds `cr.regulad.xyz`'s former site, with the repository as `{args[0]}`, which Caddy (2.11.9) substitutes in matchers and rewrite targets alike. `caddy adapt` of the old and new `cr` sites gave identical JSON but for an auto-numbered route group (`group1` and `group5`).
- **`caddy adapt` in a container:** inside `pct exec`, Caddy cannot open `/dev/stdin` ("permission denied"), though stdin passes through. Write the input to a `mktemp -p /dev/shm` file, adapt it, and remove it.
- **Auto-updates take the mirror too:** containers-registries.conf(5) promises mirrors only for "reading a single image". But a `podman auto-update --dry-run` on uptime asked Nexus's `docker-io` proxy for `louislam/uptime-kuma`'s manifest, by tag and by digest, as `svc-homelab`. Podman 5.7.0.
- **A new Cloudflare record** answered empty from 1.1.1.1 and on the LAN for a few seconds after its apply; Cloudflare's own nameserver had it at once.
