# doppelgangerhq.com is served by Caddy over both IP families (2026-11-04)

- The domain published an AAAA record, but the legacy VCN's security list admitted HTTP and HTTPS from `0.0.0.0/0` alone. Every client with IPv6 waited for a timeout before falling back to IPv4, and from livekit, HTTPS over IPv6 timed out. The two rules now iterate over `local.dual_stack_internet_cidrs`. Because the list's order shifted, the plan showed every ingress rule removed and re-added; comparing before and after as sets showed only the two IPv6 rules new. OCI replaces a security list's rules in one call.
- Docker publishes the app's port 81 on every address, past firewalld, but the security list admits it only from `10.0.0.0/16` and Tailscale.
- Ubuntu's `caddy` 2.6.2 (noble-updates) replaced nginx 1.24 and certbot's snap 5.9.0. It runs as `caddy`, with its state in `/var/lib/caddy/.local/share/caddy` and the copy of its configuration it saves at each load in `/var/lib/caddy/.config/caddy/autosave.json`. Caddy 2.6.2 rejects `persist_config` ("unrecognized global option"), so AIDE excludes `autosave.json`, beside the certificates, locks and `last_clean.json` that ingress excludes.
- Caddy run as root creates `~/.step`, smallstep's trust-store directory. One `caddy validate` as root left an empty `/root/.step`, so the `validate` and the tree's `check` run with `HOME=/run/caddy-validate`.
- `host_files` writes files before it installs packages, so a `validate` that needs a package's binary fails on a host without it; livekit's nginx only worked because nginx was already there. Caddy was installed by hand first. Its first start failed on nginx's port 80, which the package's postinst tolerates (`|| true`).
- The cutover stopped nginx at 20:24:28 UTC, and Caddy had its certificate from Let's Encrypt (YE2) at about 20:26:48, so the site was down for about 2½ minutes. Let's Encrypt backdates `notBefore` by an hour.
- Caddy sets `X-Forwarded-For`, `-Proto` and `-Host` itself; `X-Real-IP` and `X-Forwarded-Port` are added, as nginx sent them. `protocols h1 h2` leaves HTTP/3 off, as on ingress, and the security list admits no UDP 443 anyway. `www.doppelgangerhq.com` has no DNS record, so the site no longer names it.
- HSTS is `max-age=63072000; includeSubDomains; preload`. Joining Chrome's preload list, which Firefox and Safari draw on, still takes a submission at hstspreload.org; the token only signals consent.
- nginx and `nginx-common` are purged, certbot's snap removed with `--purge`, and `/etc/letsencrypt` and `/var/www` deleted.
