# mail's exposed Email Delivery login, Gmail app password and regulad.xyz DKIM key are rotated (2026-11-19)

- A `sed` and `grep -v` filter over `sops -d` output of mail's `secrets.sops.yml` printed the values it was meant to hide: the two relay logins and regulad.xyz's PEM key, a multi-line block scalar whose lines the patterns did not match. AGENTS.md's hard rule 9 now sets out how to read SOPS files without printing values. SOPS encrypts YAML comments too (`#ENC[…]`), so reading a file's comments means decrypting it: pick them out with a parser that first refuses any multi-line value.
- OCI provider 9.9.0 declares `oci_identity_smtp_credential.password` only `Computed`, not `Sensitive`, as it does `oci_identity_auth_token.token` and `oci_identity_customer_secret_key.key`: `tofu show`, `tofu state show` and a plan that replaces the credential print the password. Review such a plan with `tofu show -json <plan> | jq -c '.resource_changes[] | select(.change.actions != ["no-op"]) | [.address, .change.actions]'`.
- `data "oci_identity_users"`'s `name` argument returned no user, as `svc-mail@regulad.xyz` or as `svc-mail`, though the unfiltered list has `svc-mail@regulad.xyz`: pick a user from the unfiltered list by name. A user holds at most two SMTP credentials, so a rotation by `-replace`, which destroys before creating, needs one slot free; the new credential took the second slot beside the exposed `20260815`, which went afterwards.
- Rspamd signs only while the key in DNS matches the file (`check_pubkey = true`), so the new selector's TXT record, `mail20261119._domainkey.regulad.xyz`, went into Cloudflare before mail switched to it. A message submitted with `sendmail` inside the container is signed too (`sign_local = true`), which makes it a quick end-to-end check: Gmail's `Authentication-Results` showed `dkim=pass header.s=mail20261119`, `spf=pass` and `dmarc=pass`.
- `host_files_removed_files` removes paths a host must no longer have, such as the old selector's key files; the `aide_written` callback records a `file` task's `state: absent`, so AIDE's refresh drops them from the baseline.
- Google issues app passwords through no API; each is 16 lowercase letters, shown once in four groups of four. `tofu/google/secrets.sops.yaml` keeps them, as `tofu/dockerhub` keeps Docker Hub's tokens, and mail's secrets keep only the Gmail address.
