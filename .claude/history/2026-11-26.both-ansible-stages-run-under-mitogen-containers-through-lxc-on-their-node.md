# Both Ansible stages run under Mitogen, containers through lxc on their node

- Mitogen 0.3.55 (2026-11-17) is the first release that supports ansible-core 2.22. It speeds up only the connection types it redirects to its own (`REDIRECTED_CONNECTION_PLUGINS` in `ansible_mitogen/strategy.py`: ssh, lxc, setns, docker, podman and a few others, by short name only). Any other plugin, `pct_ssh` included, runs as it would without Mitogen, so the containers moved to Mitogen's `lxc` connection, and `pct_ssh` was removed. A host that names `ansible.builtin.ssh` in full is not redirected, which is how arawi opts out.
- Mitogen's `lxc` runs `lxc-attach --clear-env -n <ansible_host> -- <python>`, on the host that `mitogen_via` names. That host must be an inventory host (`_spec_from_via`, `ansible_mitogen/connection.py`); a bare address is refused. `tofu/gonkputer`'s `nodes.tf` therefore gives each node an `ansible_host` of its own, in `proxmox_nodes` alone, and each container's `proxmox_node` references it. `gonkputer.terraform_state.yml` leaves those hosts out of `generated`, and their attribute `groups` is readable in its `groups` conditions. No play targets them, as every play names OS groups, role groups or `generated`. `--clear-env` also drops the `SSL_CERT_*` variables Proxmox sets, which `pct exec` and `pct_ssh` had to remove themselves.
- Mitogen reads a hop's variables without templating them, then templates every one of them at once (`host_vars=dict(via_vars)`, `_spec_from_via`) with no `hostvars`, `groups` or lookup paths. That failed with "A required TemplateContext context is not active" for a templated `mitogen_via`, and with "'hostvars' is undefined" for all.yml's `pam_rssh_nexus_url`. So `mitogen_via` is composed in the inventory, the node's SSH options are literals in `proxmox_nodes.yml`, and all.yml's other templates moved to `group_vars/generated.yml`, a group the nodes are not in. A variable added to all.yml must not be a template.
- Under a non-Mitogen strategy, `ansible_connection: lxc` is `community.general.lxc`, which looks for the container on the controller. So a play that needs linear execution sets `strategy: mitogen_linear`, not `linear`: these are the restic play in `ansible-common/playbooks/site.yml`, and restic's password rotation, AIDE's accept and Podman's repair in `maintenance.yml`. Their `run_once` facts and `--limit` checks must reach every host before any host goes on.
- Interpreter discovery under Mitogen failed on the hop, logged as `cannot access local variable 'stdout'` against the container, and passed once the hop named its interpreter. Every OS group's group_vars, and `proxmox_nodes.yml`, now set `ansible_python_interpreter: /usr/bin/python3`, so no host runs discovery.
- arawi, pfSense with csh as its login shell, times out at Mitogen's bootstrap, while Ansible's own SSH reaches it (2026-11-26). bailout (Oracle Linux, sudo through pam_rssh), prodingus and overture (macOS) work under Mitogen with become.
- Ansible's strategy plugins have been deprecated since ansible-core 2.19, with no replacement planned: each run warns, and a later ansible-core may drop them.
