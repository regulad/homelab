# Koala and Warlock submit to winget with Komac, so their signing keys and age keys go (2026-11-24)

- **Commits made through GitHub's API need no key of their own:** Komac commits to regubot's fork with GraphQL's `createCommitOnBranch`, and GitHub signs the commits that mutation makes with its own key and marks them verified (GitHub Changelog, 2021-09-13, "A simpler API for authoring commits"). A pipeline that submits with Komac holds only regubot's token; only one that commits with git, as regulad/jobs's Jenkins jobs do, needs a signing key of its own.
