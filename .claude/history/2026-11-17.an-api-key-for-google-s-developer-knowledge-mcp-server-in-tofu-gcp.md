# An API key for Google's Developer Knowledge MCP server in tofu/gcp (2026-11-17)

- **The server:** Google's remote MCP server at `developerknowledge.googleapis.com/mcp` takes an API key in the `X-Goog-Api-Key` header. The key, `google_apikeys_key.developer_knowledge` in `regulad`, is restricted to `developerknowledge.googleapis.com` alone and has no application restriction, because it is used from several machines.
- **API Keys API:** `google_apikeys_key` needs it (`apikeys.googleapis.com`) enabled in the key's project, as well as the API the key targets. Newly enabled services took about 20 seconds each.
- **Into Bitwarden:** the value goes through Bitwarden, not SOPS, as dotfiles reads its MCP tokens there: a Login item named `developers.google.com`, with a Hidden custom field `token`. `bw encode | bw create item` reads the item's JSON from stdin, so the key is never on a command line.
  - The Windows `bw.exe`, run from WSL through interop, broke the terminal's stdin during `bw unlock`.
  - WSL's own `bw` from linuxbrew works, with `bw sync` before and after.
