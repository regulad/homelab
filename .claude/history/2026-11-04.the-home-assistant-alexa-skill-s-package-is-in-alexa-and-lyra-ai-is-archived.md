# The home-assistant Alexa skill's package is in alexa/, and Lyra AI is archived (2026-11-04)

- The developer account `regulad` held two development-stage skills: `home-assistant`, a Smart Home skill whose endpoint is `tofu/aws`'s Lambda, and `Lyra AI`, an Alexa-hosted custom skill from 2024-08 that answered questions through perplexity.ai and sold query packs and a subscription as in-skill products. The Google Assistant skill whose backend was the `AlexaAssistant` stack no longer existed.
- Lyra AI's code was in no repository. `regulad/lyra` held only its `gh-pages` site, the skill's page, privacy policy and terms, and `regulad/lyra-rd` is an unrelated remote-desktop app. The code, downloaded from the developer console's Code tab, is now `regulad/lyra`'s `master`, its default branch, as one commit dated to the skill's last update. Its `lambda/.env`, which held a `PERPLEXITY_API_KEY`, is gitignored there. Both repositories are archived. The skill was deleted after its four in-skill products were unlinked and deleted.
- An Alexa-hosted skill's code is a CodeCommit repository in Amazon's account, read through `ask util git-credentials-helper`. The helper finds the skill through an `ask-resources.json` in its working directory. When it failed, Git for Windows fell back to Git Credential Manager's interactive sign-in window. The console's Download Skill zip holds the package and the code.
- ASK CLI 2.30.7 differs from Amazon's command reference. The vendor listing is `ask smapi get-vendor-list`, not `list-vendors`, and `get-isp-list-for-vendor` takes the vendor from the profile, with no `--vendor-id`. `ask smapi --help` lists the real subcommands. `export-package` writes a `skill-package` folder into the current directory.
- No tool tracks a skill's state. CloudFormation's registry reports `Alexa::ASK::Skill` as NON_PROVISIONABLE, with no handlers, so Cloud Control and the `awscc` provider cannot manage it. The one OpenTofu provider, `thomas-b-jackson/alexaskills`, has released only betas and has had no commits since 2022. Modules for Home Assistant's skill cover only its AWS Lambda and IAM.
- `get-account-linking-info` never returns the client secret. The settings are kept encrypted because they hold Home Assistant's public URLs.
- AWS account IDs are plaintext from here on, as AWS does not consider them secret.
