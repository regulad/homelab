# AIDE leaves ClamAV's quarantine and Ubuntu Pro's machine token alone (2026-11-03)

- **Every clamonacc start leaves a lock file in the quarantine.** clamonacc's `--move` creates `.clamav-quarantine-lock.<pid>.0` in the quarantine at start and removes it only at a clean exit, which its unit's `SIGKILL` never allows, so each restart on any clamonacc host leaves one; aboriginal held 83. clamav-scan moves files itself and leaves none.
- **The tradeoff taken: the whole quarantine, `/root/quarantine`, is excluded on every Linux host,** not only the lock files: the role's exclusions are paths, and the locks' names change with each process ID. Every file ClamAV moves there, from clamonacc or the weekly scan, is mailed by ClamAV already and would have been reported again by AIDE. Lost: AIDE no longer sees anything else put in the quarantine, which ClamAV never scans either; only root can write there. The alternative, if quarantined files are ever wanted watched again, is an exclusion by pattern in aide-report, for the locks alone.
- **Ubuntu Pro's metering rewrites its machine token files.** On a host attached to Pro, as aboriginal is for Livepatch alone, `ua-timer.timer` runs the client's `metering` job, which reports the machine's activity to Canonical's contract server and writes the `activityInfo` it returns into `/var/lib/ubuntu-advantage/private/machine-token.json` (root's: the machine token, each service's token, the contract's entitlements and account) and its world-readable copy without the tokens, `/var/lib/ubuntu-advantage/machine-token.json`. Both are excluded on every host, with `jobs-status.json`. Lost: AIDE no longer notices an attachment to another account, a replaced token or changed entitlements, which change through the contract server or `pro attach` and `detach`. Kept: `uaclient.conf`, which names the contract server, the client's own files, and the Livepatch snap, whose kernel patches Canonical signs.
- **lime keeps a file per Mac in its state directory,** `/var/lib/private/lime/<mac>` (its unit's `StateDirectory` with `DynamicUser`), rewritten as it runs; it is excluded on aboriginal.
