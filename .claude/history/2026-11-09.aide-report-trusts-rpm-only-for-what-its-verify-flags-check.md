# aide-report trusts rpm only for what its verify flags check (2026-11-09)

- **rpm passes whatever a file holds where `%verify(not ...)` clears the check.** setup clears the digest, size and mtime of `/etc/passwd`, `shadow`, `group`, `hosts` and the rest, so `rpm --verify` passes them whatever they contain, and aide-report explained any change to them as the package's, a uid-0 user added by hand included.
- aide-report now reads each file's `FILEVERIFYFLAGS` from the rpm database. A file whose digest rpm does not check is never vouched for by its package, as a `%ghost` is not, and neither is a link or copy that relies on it; a change to any other attribute rpm does not check for a file is kept in the report too.
