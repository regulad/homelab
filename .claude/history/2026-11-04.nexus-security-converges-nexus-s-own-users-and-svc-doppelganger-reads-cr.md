# nexus_security converges Nexus's own users, and svc-doppelganger reads cr (2026-11-04)

- `cloudkrafter.nexus`, the only Galaxy collection that manages Nexus's users and roles, does so through a single `config_api` role. Its areas can be chosen only by tag, and its defaults are example data, including an `admin` user with password `s3cr3t` and a sample realm order, so a run without tags could rewrite a working Nexus. `nexus_security` instead converges only the roles and local users it is given, through `ansible.builtin.uri` as `svc-ansible`.
- `uri` has no check mode, so its POST and PUT tasks are skipped in a check run. The role's last task reports what a run would create, update or reset.
- Nexus answers a wrong password with 401 even with anonymous access on. `/service/rest/v1/status/check` answers 403 both to anonymous requests and to a user whose password is right but who lacks the privilege, which is how the role tests each existing user's password.
- Anonymous access is on: `nx-anonymous` holds `nx-repository-view-*-*-read` and `-browse`, and `cr` does not force basic auth, so anyone can pull from `cr.regulad.xyz`. `svc-doppelganger`'s login matters only once that is restricted.
- `svc-doppelganger` follows `nx-aaoracled`'s precedent: a local user, and a role of the same name holding only `nx-repository-view-docker-cr-read` and `-browse`. It gets a 200 from `cr.regulad.xyz/v2/` and pull tokens, and a 403 from Nexus's REST API.
- doppelgangerhq.com reads the password from `hostvars[groups['nexus_servers'] | first]`, so there is one copy, in `nexus_servers.sops.yml`.
- `community.docker.docker_login` compares the credentials in `config.json` with the listed ones and logs in only when they differ, so a stored credential that has since been revoked still reports `ok`. In check mode it authenticates without writing.
- `community.docker` 5.4.0 is bundled with Homebrew's `ansible` 14.5.0, so `ansible-galaxy collection install` reported nothing to do. `--force` with `-p collections` installed the stage's own pinned copy, as `community.general` has.
