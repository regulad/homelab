# parkerwahle's Vercel project moves to Node 24, as Vercel discontinued Node 20

- Every deployment of regulad.xyz since 2026-11-22 failed before building: Vercel's build log, read from its API (`/v3/deployments/<id>/events`), ended at `Node.js Version "20.x" is discontinued and must be upgraded.` The project's `node_version` is now `24.x`, as ml4webedit's and doppelganger's image run, and parkerwahle's Dependabot holds `@types/node` below 25 to match.
- picture-triangulator and battleship-visualizer are still on `18.x`, which Vercel has discontinued too, so their next deployments will fail the same way.
