# doppelgangerhq.com reads Supabase's URL and API keys from `tofu/supabase`

- `supabase/supabase` 1.11.1's `supabase_apikeys` data source gives a project's `anon_key` and `service_role_key`; the project's API URL is `https://<project ref>.supabase.co`. No resource or data source of that release exposes the JWT secret, which stays in doppelgangerhq.com's `secrets.sops.yml`.
- The keys the data source returns were the ones doppelgangerhq.com's `web.env` already held: its check after the apply showed no change there.
