# News Mail, an app of the repository's own, mails each News user the new entries of each feed update (2026-11-12)

- News (29.0.0) raises one kind of Nextcloud notification, an article shared with the user, and dispatches no event for new items. Its maintainers closed sending news by email as out of scope for News itself (nextcloud/news#225), and push notifications for new items stalled (#560); no app in the App Store for Nextcloud 35 mails or notifies feed items. The notifications app mails a user's unhandled notifications in batches, hourly at most often (`setting_batchtime`), and only those another app raised.
- News fetches every feed in its own `UpdaterJob`, every `updateInterval` seconds (3600 by default) when `useCronUpdates` is on. Item IDs only grow, and `NewsMapperV2` stamps each item it inserts or updates with `last_modified` in microseconds, so `ItemServiceV2::findAllAfter($user, ListType::UNREAD, $since)`, which News's sync API uses, reads a user's recently stamped items; `ItemServiceV2::findAllForUser`'s parameters only filter by equality. Items a feed's keyword filter hides report `isFiltered()`.
- `ItemServiceV2::read($user, $id, true)` marks one of a user's items read, and throws `ServiceNotFoundException` for one gone since. The app marks each mail's entries read once it has gone out, so a run that fails partway leaves unread, and tries again, only what was not mailed.
- Another app reaches News's services through `OCP\Server::get()`, which hands a class in `OCA\News\` to News's own container; injecting them into a background job's constructor would fail whenever News is not enabled.
- A route's name is `<app>.<controller>.<action>` with its `postfix` appended directly, lowercased: News's feed and item pages are `news.page.indexview.feedid` and `news.page.indexview.itemid`.
- `IEMailTemplate::addBodyListItem` escapes its text only when no plain-text version is passed; given one, the text is HTML as it stands. `addBodyButton` escapes its label. A message with no sender gets `Util::getDefaultEmailAddress('no-reply')`, `mail_from_address` at `mail_domain`, under the theming name.
- `occ upgrade` disables an app only if the App Store has no release of it for the new major and its installed `info.xml` does not allow that major. Nextcloud compares a `max-version` to as many parts as it has, so `35` allows every 35.x and no 36, and an app without one allows every major. Raising an enabled app's version leaves `occ status --exit-code` at 2 until `occ upgrade` runs, and Nextcloud serves only its update page meanwhile.
- `ansible.builtin.fileglob` expands a wildcard only in a path's last part; `community.general.filetree` lists a tree for matching deeper paths.
