# uulanding's Vercel project is destroyed and regulad/uulanding archived

- The Unblockable Unblockers work is retired. Its landing page, the Vercel project `uulanding`, was the only part still deployed: the `unblockable-unblockers` organization's six repositories were already archived, and none served a GitHub Pages site. No DNS record in `tofu/cloudflare` pointed at the project, so removing `project-uulanding.tf` was the whole change. `uulanding.vercel.app` answered 503 before the destroy and 404 after it.
- `tofu init` for `tofu/vercel` needs the decrypted inputs first, because the state encryption reads `var.state_encryption_passphrase` during init: run `sh tofu/vercel/prepare.sh` before it. The `tofu-validate-vercel` pre-commit hook fails until the root is initialized, so a clone without `tofu/vercel/.terraform/` can't commit a change to the root before running `init`.
