# Enterprise Linux reboots when needs-restarting says so (2026-11-09)

- **dnf 4's `reboot = when-needed` checks a fixed list of package names,** which has no `kernel-uek` or `kernel-uek-core`, so a UEK update alone never rebooted an Oracle Linux host: mail ran its old kernel for 65 hours after 11-04's update.
- dnf-automatic now sets `reboot = when-changed` with a `reboot_command` of `dnf needs-restarting -r >/dev/null || shutdown -r +5 ...`: after every run that changed something, it reboots five minutes later when a package on needs-restarting's list was installed since boot. Oracle's build of the list includes the UEK packages. The command fails toward rebooting, as needs-restarting exits 1 on an error too.
- needs-restarting comes from dnf-plugins-core, which the `auto_updates` role now installs with dnf-automatic: wako's AlmaLinux 10 image had none.
