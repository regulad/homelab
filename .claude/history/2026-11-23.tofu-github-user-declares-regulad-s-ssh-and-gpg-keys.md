# tofu/github-user declares regulad's SSH and GPG keys (2026-11-23)

- **One SSH key, two registrations:** `id_rsa3072` is both regulad's authentication key (`/user/keys`, ID 102565467) and his signing key (`/user/ssh_signing_keys`, ID 718057), separate resources on separate endpoints. Their titles differ in case, `regulad@stalactite` and `regulad@Stalactite`, and a title forces a replacement, so each keeps GitHub's.
- **GPG keys:** GitHub returns an uploaded key as `raw_key`, byte for byte, CRLF line endings included for this one. The pinned build imports a GPG key by its GitHub ID (2314907 here) and compares the armored key ignoring line endings and surrounding whitespace, so an LF copy imports with no change.
- **Labels and file names:** a resource label cannot start with a digit, so the GPG key is named `x` and its key ID, `x081BE541EA23ACF3`, in its label and its `gpg-key-<name>.tf`.
- **Import blocks and workspaces:** `tofu validate` passes in `bot` with import blocks that target resources disabled there; they are removed after the `personal` apply, before `bot` is planned.
