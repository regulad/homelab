# closecircuit and SupIR sign releases from signing.sops.yaml, each under its own password (2026-11-17)

- **The structure is doppelganger's:** each repository commits `signing.sops.yaml` (`keystore`, base64 PKCS#12; `password`; `alias`), encrypted to Parker's age key and to an age key of the repository's own. That key's identity is the repository's one Actions secret, `SOPS_AGE_KEY`, kept in `tofu/github/secrets.sops.yaml` as `closecircuit` and `supir`. Tagged builds install a sha256-pinned SOPS 3.13.3 and decrypt before `assembleRelease`.
- **One key signs both apps:** alias `regulad`, certificate `CN=Parker Wahle` from 2024-10-20, SHA-256 `17:36:96:5A:37:DB:22:56:7B:D2:85:FB:4C:66:83:80:91:26:DF:7C:34:98:FC:19:60:4F:30:DE:C1:D6:00:E4`.
  - `keytool -printcert -jarfile <apk>` reads it from a release APK, which is how any copy of the key is checked.
  - IzzyOnDroid distributes both apps and pins the certificate, so the key itself must never change.
  - A test tag would publish a release to their users.
- **The original keystore:** `regulad.jks` is PKCS#12 despite its name. Its password is the Bitwarden note `regulad.jks`. The file itself was in no chezmoi source and no Bitwarden attachment; once both copies were made, it was shredded. Parker's age key opens either repository's copy.
- **Re-wrapping:** `keytool -importkeystore` with `-deststorepass:file` re-encrypts a PKCS#12 under a new password, so each repository's copy has a password of its own.
  - In PKCS#12 the key's password follows the store's, so one `password` serves both Gradle properties.
  - `openssl pkcs12 -nocerts -nodes -out /dev/null -passin file:<f>` confirms the key opens without printing it.
- **Encrypting from stdin:** `sops encrypt --filename-override <name> --input-type yaml --output-type yaml /dev/stdin`, run in the repository, applies its `.sops.yaml` rules without the plaintext touching disk. `sops set --value-stdin` takes a JSON value, so a raw value goes through `jq -R -s .` first.
- **Checking a recipient alone:** decrypt with `SOPS_AGE_KEY_FILE` set and `XDG_CONFIG_HOME` pointed at an empty directory, so SOPS cannot fall back to the default keys file.
- **`android-actions/setup-android@v3`:** its default packages, `tools platform-tools`, fail, because Google's SDK repository no longer has the legacy `tools` package; `packages: "platform-tools"` fixes it. Every run had failed that way: SupIR's since 2026-09-15, closecircuit's since at least 2026-11-15.
- **Lint:** `./gradlew build` runs full lint, while `assembleRelease` runs only lint's fatal checks. closecircuit's debug job failed on `UnusedMaterial3ScaffoldPaddingParameter`, which is now suppressed on `MainActivity.onCreate`, as the content is fullscreen on purpose.
- **Searching Windows from WSL:**
  - WSL escapes a `cmd.exe /c` argument's embedded double quotes with backslashes, and a trailing backslash before its closing quote also breaks it; either way, `dir` fails silently. Write patterns such as `H:\*.jks` without quotes.
  - Google Drive for desktop and the NAS share are drive letters (G:, H:, I:, Z:) that are not mounted under `/mnt`.
