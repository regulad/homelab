# tofu/gcp adopts the four Google Cloud projects kept, and eleven are deleted (2026-11-04)

- OpenTofu signs in as `homelab-tofu@regulad` with an uploaded key. The key pair was generated locally, and only its certificate was uploaded (`gcloud iam service-accounts keys upload`), so Google never had the private key. `prepare.sh` builds the JSON key file Google would otherwise hand out, in memory, from the SOPS key, the key ID Google assigned and the account's email. There is no organization, so no policy blocked the upload. Each project grants the account Owner in its own IAM policy, made in Cloud Shell by looping over `gcloud projects list`.
- Calls made as the service account are billed to its own project, so each API they reach must be enabled in `regulad`. The provider reads every project's billing link through the Cloud Billing API, which was off there; every `billingInfo` call returned 403 until it was enabled. Only `regulad` has billing.
- Discovery needs no `gcloud`. A JWT signed with `openssl dgst -sha256 -sign` and exchanged at `oauth2.googleapis.com/token` gives an hour's access token. Cloud Asset Inventory's `projects/{p}:searchAllResources` then lists everything in a project, which a service-by-service sweep would miss. Only the API in the caller's project needs to be on.
- OAuth 2.0 client IDs cannot be listed. No public API exists, Cloud Asset Inventory does not index them, and the console's private `clientauthconfig` API returned INVALID_ARGUMENT to the service account. The provider has no resource for them, so they stay unmanaged; a deleted project takes its clients with it. A client ID begins with its project's number, so a config that holds one shows which project it belongs to.
- Provider findings, v8.10.0:
  - `google_service_account_key` cannot be imported.
  - `google_project`'s `labels` covers only the labels written in HCL. Declaring Firebase's `firebase=enabled` planned an update, so it is left to Firebase.
  - `google_project_service` imports as `{project}/{service}`, and `google_project_iam_member` as `"{project} {role} {member}"`. Separate grants per member leave everyone else's bindings alone.
- Deleted, restorable until 30 days after: the projects `gen-lang-client-0969045816`, `recaptcha-migrated-235ae77805f`, `filefly-432713`, `pure-toolbox-429813-a4`, `bluebubbles-a3ae`, `carcomms-b156a`, `friendlychat-3120f`, `mystical-moon-373318`, `assistant-for-windows-b57cc`, `snappy-way-323701` and `matrix-synapse-1733678924367`. A project read back as ACTIVE for a few seconds after its DELETE succeeded, then DELETE_REQUESTED. Of the two `matrix-synapse` projects, created in the same second, Synapse's `recaptcha_public_key` named `…090`'s key, so `…367` went.

  - Its 14 scheduled snapshots and the schedule.
  - The Ops Agent OS policy assignment the console had generated with it, which reports `deleted: true` while it reconciles.
