# dodo's and vkasm's Docker mirror Docker Hub at docker-cr.regulad.xyz, with a reload (2026-11-18)

- **`registry-mirrors` needs no restart:** Docker's "Configuration reload behavior" lists it among the daemon.json settings `dockerd` takes on SIGHUP, which `systemctl reload docker` sends (`ExecReload=/bin/kill -s HUP $MAINPID`, in Ubuntu's 29.1 and Docker CE 29.10 alike). The docker role now reloads where only such settings changed, and dodo's game server and vkasm's Kasm services kept running through the change.
- **The docker role compares parsed settings key by key:** a key that is new, gone or of another value counts as changed, so a file rewritten only in its formatting (Docker's tabs and its key order against `to_nice_json`) changes nothing and notifies nothing.
- **Kasm's image ships no `/etc/docker/daemon.json`,** so vkasm's holds `registry-mirrors` alone, from `host_files`. vkasm stays out of `docker_hosts`, whose role would install Ubuntu's `docker.io` over Kasm's Docker CE.
- **`docker info` shows the mirror with a trailing slash,** `[https://docker-cr.regulad.xyz/]`, whatever daemon.json says. Docker mirrors Docker Hub alone, so dodo's Wings still pulls its ghcr.io images directly.
