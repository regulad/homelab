# Homelab IaC history

What was done, with the technical findings worth knowing later, one entry per
file. Current rules and intent live in `AGENTS.md` and `.claude/PLAN.md`; this
directory keeps how they came about. Each entry is a title saying what was done
and the findings that would help a future session.

Entries are named `<date>.<slug>.md`: the date the work was done and its
title in lowercase words joined by `-`, so that they sort by date. Names carry
no sequence number, since several agents add entries at once. Add a new entry
as a new file.
