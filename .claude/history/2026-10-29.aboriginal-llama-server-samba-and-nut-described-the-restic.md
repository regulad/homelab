# aboriginal: llama-server, Samba and NUT described; the restic mounts wait out a cold boot (2026-10-29)

- At the cluster's cold boot of 2026-10-29, aboriginal's DHCPv4 lease came at 02:44, four minutes in, as arawi started; until then it had only IPv6's link-local address, and B2 was out of reach. restic kept retrying, but `mnt-restic.service` failed at systemd's default 90 s start timeout, and with it every unit requiring the mounts: `mnt-nas`, `mnt-media`, Docker and smbd. Docker came back at 02:45 through its socket; nothing restarts smbd, so Samba stayed down. `TimeoutStartSec=infinity` on `mnt-restic.service` makes them wait.
- nmbd, ordered after `network.target` and a winbind that no longer exists by a hand-made drop-in, timed out the same way. The drop-in is replaced by one that restarts it on failure, with no start limit, so its packaged `After=network-online.target` applies again.
- `nut.target` wants `nut-monitor.service`, so a disabled upsmon still started at boot and failed five times ("insufficient power configured": `MINSUPPLIES 1` with no `MONITOR` line). It is masked.
- NUT keeps upsd's passwords in plain text in `upsd.users`; that file is a template of the package's own, the password in SOPS. `nut-driver-enumerator.path` restarts the drivers when `ups.conf` changes, and `nut-server` reloads its users with `upsd -c reload`.
- llama-server's llama.cpp is ggml-org/llama.cpp at `458681e1d`, built with HIP, Vulkan, `GGML_NATIVE` and shared libraries for gfx1030. Its tree carries one local change: `launch_fattn` clamps `max_blocks_per_sm` to 1, where `GGML_ASSERT(max_blocks_per_sm > 0)` failed because HIP's occupancy API reports 0 on RDNA2 (ggml-org/llama.cpp#23310). HIP builds compile `ggml-cuda`'s sources, so the change is in the binary.
- `maintenance.yml`'s `jellyfin-upgrade-cleanup` removes what `jellyfin-upgrade` leaves, the copy, the plugin downloads and the images of other major releases, once Jellyfin runs healthy on the declared release. The two plays share their variables through a YAML anchor.
