# /tmp is a noexec tmpfs by systemd's tmp.mount, and AIDE refreshes the links of the units a run enables (2026-11-03)

- **Mount units cannot be templated.** systemd.mount(5): "mount units cannot be templated, nor is possible to add multiple names to a mount unit", as each is named for its mount point. The `noexec` role renders one unit per path instead, from `noexec_paths` and each host's `noexec_paths_host` (ncsusplitt's `/opt/pipx/logs`, pipx's log of each command it runs).
- **`systemd-escape` prints every name on one line, separated by spaces.** Read a line per name, two paths became one unit file named for both (`var-log.mount opt-pipx-logs.mount`, removed by hand from ncsusplitt). The role splits its output on whitespace, which escaped names never hold, and checks it has a name per path.
- **How each release ships `tmp.mount`.**
  - Debian 13 and Ubuntu 26.04: in `/usr/lib/systemd/system`, `static`, pulled in through `/usr/lib/systemd/system/local-fs.target.wants`, and active, so `/tmp` was already a tmpfs, with `mode=1777,strictatime,nosuid,nodev,size=50%%,nr_inodes=1m` (Ubuntu 26.04 adds `x-systemd.graceful-option=usrquota`).
  - Ubuntu 24.04: in `/usr/share/systemd`, outside systemd's search path, with `WantedBy=local-fs.target`; the role links it in with `systemctl link`. doppelgangerhq.com had it linked by hand since 2025-11-01.
  - Oracle Linux 9 and AlmaLinux 10: in `/usr/lib/systemd/system`, disabled, with `/tmp` on the root filesystem.
- **`noexec` is a drop-in, `tmp.mount.d/noexec.conf`.** A drop-in's `Options=` replaces the unit's, so it repeats the options of the unit the host has, read from its file at each run, with `noexec` added, and `%%` kept as written. Where tmp.mount already had `/tmp` mounted, `systemctl reload tmp.mount` remounts it with them, which keeps the tmpfs and the directory clamonacc watches. In an unprivileged container the tmpfs shows `uid=100000,gid=100000` and a size of half the node's RAM, charged to the container's memory cgroup.
- **Where `/tmp` was on the root filesystem, the tmpfs comes at the next boot.** Mounting it now would hide the files running services keep in `/tmp`, and leave clamonacc watching the directory beneath, as it marks directories, not mounts, until it restarts. Before each mount, `tmp-erase.service` (a oneshot with `DefaultDependencies=no`, `ConditionPathIsMountPoint=!/tmp` and `Before=tmp.mount`, running `find /tmp -mindepth 1 -xdev -delete`), pulled in by `tmp.mount.d/erase.conf`, erases what the root filesystem holds there, which the tmpfs would otherwise hide. A mount unit runs no commands of its own: `[Mount]` has no `Exec*=` settings. It is installed only where `tmp.mount` is not `static`.
- **What runs from `/tmp` is in containers with their own.** Jenkins, Nexus and timemachine's quadlets and Jellyfin's Compose file mount a tmpfs of their own at `/tmp`.
- **ansible-core 2.21 no longer adds `invocation` to task results** (`INJECT_INVOCATION`, default false), so the aide_written callback found no module arguments: since then it had missed what `lineinfile` and `blockinfile` wrote, which their results do not name. Both stages set `inject_invocation = true`.
- **AIDE's refresh covers the links of units a run enables, disables or masks.** `systemctl enable` makes `/etc/systemd/system/<target>.wants/<unit>`, and the directory when it is new, which no file module writes. The callback records each unit a `systemd_service`, `systemd` or `service` task changed with `enabled` or `masked`, and `aide-report --refresh --units` moves the baseline for its links: its own name in `/etc/systemd/system` (a mask or a link), and its name in any `.wants`, `.requires` or `.upholds` directory, there now or at the baseline, with each such directory that holds one now. A link of another name, from `Alias=`, is not covered. bailout, wako and ncsusplitt were applied before `inject_invocation`, and their links were refreshed by hand.
- **A refresh waits for aide-report's lock** while the host's daily check runs: on doppelgangerhq.com, 16 minutes before its `aide --update` began.
