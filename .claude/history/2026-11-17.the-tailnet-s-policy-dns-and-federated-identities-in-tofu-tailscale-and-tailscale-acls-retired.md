# The tailnet's policy, DNS and federated identities in tofu/tailscale, and tailscale-acls retired (2026-11-17)

- `tailscale/tailscale` 0.30.0 covers the tailnet's whole configuration:
  - `tailscale_acl` (imported as `acl`) takes the policy file as HuJSON and keeps its comments;
  - `tailscale_dns_configuration` (imported as `dns_configuration`) replaces the whole DNS configuration, as `tailscale-acls`' `dns.yml` did;
  - `tailscale_federated_identity` (imported by its key ID) is the trust credential GitHub Actions runs exchange their OIDC token with.
- The policy is a `templatefile()`. Before writing it, check that rendering it with the live values reproduces the live policy.
  - **Address expressions:** every resolver's and the Oracle VCN's address is a template expression, so no public IPv6 literal is committed. Those addresses fill `dns.tf` too, from one `local.resolvers`.
  - **Comparison:** the provider compares policies by `hujson.Format`'s canonical form, which ignores indentation but not comments.
  - **Diffs:** once a change is planned, the diff shows the state's text, which is Tailscale's canonical form: tabs, no column alignment. A template written in another format shows every line as changed, so this one was rebuilt from the live policy (`GET /acl` with `Accept: application/hujson`).
- **tofu/oracle `tailnet` output:** carries the services subnet's prefixes and pihole2's and tailscalerouter's addresses. It is sensitive, as it derives from the encrypted /64, so tofu/tailscale reads it through `nonsensitive()`, and policy and DNS plans show the addresses. Adding the output moved alock's record for tofu/oracle and its hosts.
- **Identity descriptions:** a federated identity's `description` defaults to `""` in the provider, while Tailscale stores none as `null`. An identity made without one therefore plans an update on import.
- **tailscale-acls' identity:** its repository was archived, so the identity was deleted rather than adopted. A deleted key still answers `GET` with `revoked` set and `invalid: true`, and drops out of the key list.
- **GitHub's OIDC `sub`:** these repositories use GitHub's immutable subject format, `repo:regulad@52430642/<repo>@<repo id>:ref:refs/heads/<branch>`, as `GET repos/<owner>/<repo>/actions/oidc/customization/sub` shows. Each identity's `subject` matches its default branch exactly.
- **kodi-plugins:** got a federated identity, granting `auth_keys` with the policy's existing `tag:ci-kodi`. That replaces its hand-made `ci-kodi` auth key, which expires on 2026-12-23. Its workflow moves to `oauth-client-id`, `audience` and `tags` with `tailscale/github-action` v4.4.0 and `id-token: write`, as doppelganger's and PepperCord's already use.
- The shared `tailscale_api_token`, the tailnet's `homelab` API access token with every scope, authenticates the provider. It expires on 2027-02-14.
