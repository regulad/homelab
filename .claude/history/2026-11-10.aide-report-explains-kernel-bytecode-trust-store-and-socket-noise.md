# aide-report explains kernel, bytecode, trust-store and socket noise (2026-11-10)

- **A report over 400 lines is never accepted, so volume is what matters.** The arm64 UEK hosts (livekit, mail, pihole2, riko) got about 830 entries per kernel update from device trees, and dodo 851 from rebuilt bytecode, which kept each report repeating daily. Rare, short and security-relevant changes stay reported and are accepted with their mail.
- **UEK's device trees:** `kernel-uek-core` lists `/boot/dtb-<release>/**` as `%ghost` copies of its regular files under `/usr/lib/modules/<release>/dtb/`, which grubby's `/usr/lib/kernel/install.d/10-devicetree.install` copies. On an add, that plugin points `/boot/dtb` at `dtb-<release>`; on a remove, at the newest remaining. The copies are checked byte for byte as `KERNEL_COPIES`, and the link as one of `KERNEL_LINKS`.
- **Bytecode:** py3compile's rebuilds after an upgrade are byte-identical to `py_compile` of the dpkg-verified source, with `dfile` the source's own path and the invalidation mode from the header's flags (0 timestamp, 1 unchecked hash, 3 checked hash). On dodo all 851 `.pyc` of twisted matched. Only this interpreter's cache tag is compiled; nothing is unmarshalled or run.
- **Enterprise Linux's trust store:** `update-ca-trust extract -o DIR` exists on Oracle Linux 9.8 and 10.2 and AlmaLinux 10.2. Extracted into a directory holding the tree's directories, every file and link matches `/etc/pki/ca-trust/extracted` except `java/cacerts`, whose keystore records when each entry was extracted. `pem/directory-hash/*.0` are relative links to the `.pem` beside them. On EL10, `/etc/pki/tls/certs/<hash>.0` are absolute links to `directory-hash/<name>.pem`.
- **Debian's kernel leftovers:** kdump-tools keeps `/var/lib/kdump/{initrd.img,size_initrd.img,mem,latest_sysctls}-<release>` and the links `vmlinuz` and `initrd.img` there, and dpkg a `linux-update-<release>` trigger. depmod rewrites a removed kernel's `modules.*`, which stay until a purge. DKMS's modules built for a new kernel stay reported.
- **Sockets:** AIDE's summary type for a socket is `s`. The Oracle Cloud Agent's plugin sockets in `/var/lib/oracle-cloud-agent/tmp` (`srw-rw----`, owned by `oracle-cloud-agent` or `ocarun`) exist on the Enterprise Linux instances too. The agent recreates them, and the directory itself, at each start, so a noexec bind there is impractical. fluentd's in `/etc/unified-monitoring-agenttmp` are `srwx------`. A socket added that any user may write to stays reported.
- **Left reported on purpose:** each Enterprise Linux boot entry's `options` line has tuned's `$tuned_params` at a different place, so it cannot be rebuilt from `GRUB_CMDLINE_LINUX`. podman-compose rewrites `/etc/containers/networks/<project>_default.json` with a new `created` time whenever the project comes up. oci-linux-config's `%post` also runs `/usr/lib/oci-linux-config/misc_updates.sh`, which appends `rd.iscsi.ibft=1 rd.iscsi.firmware=1` to `GRUB_CMDLINE_LINUX` in `/etc/default/grub`.
- **Caddy on ingress** keeps its data in `/caddy`, and rotates its Encrypted Client Hello keys in `/caddy/ech/configs/<n>/`.
