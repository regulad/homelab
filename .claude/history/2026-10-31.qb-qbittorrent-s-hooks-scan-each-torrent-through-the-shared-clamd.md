# qb: qBittorrent's hooks scan each torrent through the shared clamd (2026-10-31)

- qBittorrent 5.3.0's Web API takes an API key as `Authorization: Bearer <key>`, and skips its CSRF check for such requests. A key is `qbt_` and 28 characters of `[2-9A-NP-Za-hjkmnp-z]`, kept as `[WebUI] APIKey` in `qBittorrent.conf`; the API can only rotate one (`app/rotateAPIKey`) or delete it, not take a key given. The `qbittorrent` role uses the copy in qb's `secrets.sops.yml`; qb-clamav reads qBittorrent's own.
- qBittorrent connects its "Run external program" hooks for torrents added and finished only once its session is restored (`application.cpp`), so torrents loaded at start fire neither. `torrents/setLocation` turns a torrent's automatic management off (`torrentscontroller.cpp`), so a torrent staged by category is released by clearing the category, which moves it while `torrent_changed_tmm_enabled` is on.
- `app/preferences` reports paths without a trailing slash (`/downloads`), though `qBittorrent.conf` keeps `DefaultSavePath=/downloads/`; declared values match the API's form.
- LinuxServer's qBittorrent image (Alpine 3.24) carries python3, curl, jq and nc, but no clamdscan; qb-clamav speaks clamd's INSTREAM with Python's standard library.
- A file bind-mounted into a container keeps the inode it was mounted with, and Ansible replaces a file by renaming a new one over it, so qb-clamav is mounted by its directory, and a new version needs no restart.
- In the clamd container, Podman's tmpfs `/tmp` reports the node's size (62.3G), so the container's memory, now 10 GiB, bounds what clamd spools there. clamd logs its limits at each start: "Global size limit set to 4194304000 bytes" and "File size limit set to 2146435072 bytes" after the change.
- A test that needs no peers: a private, trackerless single-file torrent whose data is already in the incomplete path, added stopped and started once the added hook staged it. qBittorrent checks it, finishes it, moves it to staging and runs the finished hook within two seconds; EICAR was quarantined and mailed, a harmless file released to `/downloads`.
