# The Oracle Linux instances have no gssproxy (2026-11-05)

- gssproxy came with the images' nfs-utils and served only the NFS client's Kerberos: its one configuration besides the defaults was `/etc/gssproxy/99-nfs-client.conf`. Its unit was disabled; the NFS client had started it at boot. Once nfs-utils was removed, no package required it, so `host_files_removed_packages` now lists it on the rhel instances too, and its removal stopped it.
