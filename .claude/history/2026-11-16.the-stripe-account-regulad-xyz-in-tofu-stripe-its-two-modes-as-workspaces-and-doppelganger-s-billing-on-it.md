# The Stripe account regulad.xyz in tofu/stripe, its two modes as workspaces, and Doppelganger's billing on it (2026-11-16)

- Every Stripe account except regulad.xyz (acct_1Th8iPBuafhImQpy) had been deleted, and it held nothing, so nothing was imported. Its sandbox, the `sandbox` workspace, is precisely what Stripe calls the account's Test mode, not one of the Dashboard's Sandboxes; it mirrors live.
- A key carries its account's ID right after its `_live_` or `_test_` prefix (`51Th8iPBuafhImQpy` here), which tells which account a key belongs to without calling the API.
- Stripe has no API for its API keys: secret, restricted and publishable keys are made, edited and rolled only in the Dashboard, so the root manages none. A publishable key is one per mode for the whole account. Restricted keys take None, Read or Write per resource, can be edited after creation, and show a live key's value only once; their IP allowlist takes IPv4 alone, as `api.stripe.com`, `hooks.stripe.com` and Stripe's other API and Dashboard hosts are IPv4-only (only the Stripe.js CDN hosts have AAAA records). Events is a read-only permission; webhook endpoints are their own, `webhook_write`.
- With workspaces, the provider takes `var.api_keys[terraform.workspace]`, so a key never meets the other mode's state. A root that declares nothing never configures its provider, so the `default` workspace planned an empty no-op until `account.tf`'s output, which indexes the same map, made a plan there fail. alock locks and records the root as one target, and counts `tofu workspace new` as a change.
- `cloud.terraform.tf_output` reads another workspace by setting `TF_WORKSPACE` for its own `tofu output` alone, leaving the selected workspace as it is. Called without an output name, it returns every output wrapped as `{sensitive, type, value}`.
- `stripe_price`'s `transfer_lookup_key` is write-only, kept in no state. Doppelganger's webhook endpoint is live only, as production verifies events with the live endpoint's secret alone; the endpoint's secret is returned only when it is created.
- doppelgangerhq.com's `web.env` and `cron.env` became dicts in host_vars, with the secrets in the `doppelganger_web_secrets` SOPS map. The env string also held `PM2_PUBLIC_KEY` and `PM2_SECRET_KEY`, which a name listing that matched only letters and underscores missed; listing names needs `[A-Z0-9_]`. PM2 was retired and its key revoked, and `REACT_EDITOR` dropped.
