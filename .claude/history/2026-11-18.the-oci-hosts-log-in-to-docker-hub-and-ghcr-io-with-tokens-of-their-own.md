# The OCI hosts log in to Docker Hub and ghcr.io with tokens of their own (2026-11-18)

- **Oracle hosts no Docker Hub mirror:** OCI Container Registry's pull-through cache repositories cache only "from a Container Registry endpoint in a different OCI region within the same OCI realm", not from Docker Hub, ghcr.io or any other outside registry. So the hosts outside the homelab sign in to the public registries themselves, each with its own token, while the homelab's hosts are to pull through Nexus.
- **Which OCI hosts pull from where:** doppelgangerhq.com pulls from Docker Hub (`redis:8`), ghcr.io (its app and cron) and cr.regulad.xyz (the devices, as `svc-doppelganger`); mail and pihole2 pull from ghcr.io alone. No other OCI instance runs containers.
- **`registry_auth` replaces the docker role's `docker_login`:** `docker_login` logs in again only when a listed registry's credentials differ, so a login dropped from the list stayed in the file. The new role writes root's credential file whole. Docker's CLI keys Docker Hub as `https://index.docker.io/v1/`, Podman as `docker.io`.
- **Podman as root finds `/root/.config/containers/auth.json` from a systemd service:** `systemd-run --wait --pipe --quiet podman login --get-login ghcr.io` prints the username there, as a Quadlet's service would see it. Podman reads that file after `/run/containers/0/auth.json`, which `podman login` writes and a reboot clears.
- **`sops unset <file> '["key"]'`** (sops 3.13) removes a key without opening the file. It took doppelgangerhq.com's `docker_ghcr_token`, the personal token its Docker had logged in to ghcr.io with.
