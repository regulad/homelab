# RSSHub requires its access key, and News's feeds carry per-route codes (2026-11-05)

- With `ACCESS_KEY` set, RSSHub answers 403 on every path but `/`, `/robots.txt`, `/favicon.ico` and `/logo.png`, `/healthz` included, unless the query carries `key=<key>` or `code=`: the MD5 of the request's pathname, percent-escapes kept (`/asus/bios/PRIME%20X570-PRO/en`), followed by the key. A `code=` URL opens only its own route, so feeds use codes; a new feed's code is `md5(<path><key>)`. Without a key set, RSSHub ignores both parameters, so feeds can be moved to codes before the key is applied.
- Souin on ingress keys its cache on the query too, so a response fetched with a code is never served to a request without one.
- Nextcloud News 29.0.0 keeps each feed's `url`, `url_hash` (`md5(trim(url))`) and `location`, the URL its updater actually fetches. Neither occ nor News's API changes a feed's URL, and deleting a feed cascades to its items, so URLs change by one UPDATE of all three columns, through `podman exec -i nextcloud_db_1 mariadb` on aboriginal.
- `occ news:updater:update-feed <user> <feed id>` fetches one feed at once; it takes the user first.
