# doppelgangerhq.com runs CI's web-latest, and its website is open again (2026-11-14)

- `regulad/doppelganger`'s `ci-cd.yml` tags each build of master `web-master`, `web-latest` and plain `latest` together: its `docker/metadata-action` sets `latest=false` and writes both latest tags as `type=raw` entries, enabled on master and `v*` tags. The index holds `linux/amd64` and `linux/arm64` images, each with an `unknown/unknown` attestation manifest; `docker buildx imagetools inspect --format '{{json .Image}}'` shows each platform's build time and `org.opencontainers.image.revision`.
- The compose file names `web-latest`, CI's own name, in place of `latest`, under which the image recovered from the host had been pushed. The docker role's compose entry point pulls only missing images, so the new tag's first run pulls it; `doppelganger-update.timer` keeps it current from then on.
- The legacy security list admits HTTP and HTTPS from the internet again over both families, as it did before 2026-11-08. Its ingress rules are a set: a plan that adds rules shows every rule without a `description` removed and re-added with the same values, its description "known after apply".
