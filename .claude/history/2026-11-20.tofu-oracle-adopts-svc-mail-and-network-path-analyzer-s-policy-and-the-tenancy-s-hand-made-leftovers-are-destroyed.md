# tofu/oracle adopts svc-mail and Network Path Analyzer's policy, and the tenancy's hand-made leftovers are destroyed (2026-11-20)

- A tenancy-wide comparison with state found what OpenTofu did not hold. Resource Search's `query all resources` lists most resources, but `oci search resource structured-search` takes no `--all`, so page it with `--limit 1000 --page`. It reports a bucket by its OCID, while the provider's bucket ID is `n/<namespace>/b/<name>`, so match buckets by name. Credentials never appear in Search: list them per user with `oci iam smtp-credential list`, `oci iam auth-token list`, `oci iam customer-secret-key list`, `oci iam user api-key list`, `oci iam user oauth2-credential list` and `oci iam user list-db-credentials`.
- What was left once Oracle's own and implicit resources were set aside: svc-mail's user, group and membership; the console-made `VNPA-Tenancy-Policy`; svc-mail's SMTP credential `20260815`; three manual full backups from 2026-06-21, of mail's, livekit's and tailscalerouter's boot volumes, which never expired and had no deletion protection; and a console history of tailscalerouter from 2025-12-08. Parker's API signing key and `svc-tofu-state`'s customer secret key stay outside OpenTofu by design.
- Network Path Analyzer's console makes `VNPA-Tenancy-Policy` the first time the analyzer is used: five read statements, each scoped by `request.principal.type = 'vnpa-service'`.
- OpenTofu 1.13.9 evaluates data sources and resource attributes in an import block's `id` and `for_each`, so the imports looked every ID up and wrote no tenancy OCID into the repository. An SMTP credential's import ID is `users/<user OCID>/smtpCredentials/<credential OCID>`; a membership's comes from `data "oci_identity_user_group_memberships"` filtered by user and group.
- Deleting what was made by hand went in two applies: the first imported each object into a bare resource in a temporary file, and the next commit removed that file, so its plan showed only the destroys. An `oci_core_boot_volume_backup` or `oci_core_console_history` imports with no arguments beyond the console history's `instance_id`. Deletion returns at once; the backups then show `TERMINATED` in `oci bv boot-volume-backup list`.
- Oracle requires a description on `oci_identity_user` and `oci_identity_group`, so adopting ones made without it updates the description in place.
- A plan that destroys an SMTP credential prints its password in its text, as one that replaces it does, and `tofu show -json` of any plan or state that holds one carries the password. Save such a plan without its text, and pipe its JSON straight into `jq`, never to a file.
