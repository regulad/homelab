# FreeIPA's declared accounts merge a public and a private list, and Email Delivery's senders come from them (2026-11-20)

- `freeipa.ansible_freeipa`'s `ipauser` runs through ipalib on the FreeIPA server itself (`ipaapi_context: server`), signing in with `ipaadmin_principal`; `community.general.ipa_user` goes through the JSON-RPC API from any host. In both, a user's addresses (`email`, `mail`) are its whole list, and `ipauser`'s `action: member` covers only principals, manager, certificates and certificate mappings, so neither can add one address. `ipauser` compares the lists as sets and, when they differ, writes the list in the order given. LDAP clients take the first `mail` value as the account's address, so the public list keeps the account's first address first.
- `community.general.lists_mergeby(other, 'name', recursive=true, list_merge='append_rp')` merges the two lists by account, joining their address lists without repeating one. `community.general.keep_keys` takes a list of dicts, not one dict. ansible-core 2.21 refuses a `when` that yields a list rather than a boolean, and `ansible-lint`'s `var-naming[no-role-prefix]` wants every role variable to start with the role's name.
- An account that `ipauser` created with a password and a password expiration got the expiry FreeIPA's policy gives a new password, 90 days on, instead of the declared 2038 one; setting the expiration again once the account exists keeps it. `mail_relay`'s `null-<host>` accounts, declared with a 2038 expiry through `ipa_user`, show the same: on 2026-11-20 about half expired between 2027-01-31 and 2027-02-09, and four (null-neodingus, null-mullvad, null-lancache, null-tinker) on 2025-12-29.
- `noreply@regulad.xyz` is mail's own sender, to which `postfix-generic.regexp` rewrites root's and localhost's mail, and no FreeIPA account holds it, so `email.tf` names it beside the accounts' addresses.
- A `for_each` cannot take sensitive values, and each sender's address keys its resource, so `email_senders` is not marked sensitive: plans and state name every address. SOPS keeps them out of the repository.
- `sops encrypt --filename-override <path> --input-type json --output-type json /dev/stdin` encrypts under the path's creation rule without writing plaintext to disk. Encrypting again yields a new data key and IVs, so `bin/email-senders` rewrites its file only when the decrypted addresses differ.
- `ansible-galaxy collection install -r requirements.yml` also reinstalls the git-pinned collections; installing one collection by name and version, with `-p collections`, leaves the others as they are.
- In a Perl one-liner, `@regulad` inside a pattern interpolates an empty array, so a mask meant for `<local>@regulad.xyz` matched only `regulad.xyz` and printed the local parts. Mask addresses in Python.
