# regulad's SSH public key becomes a shared constant (2026-11-23)

- **Its source:** GitHub's record of the authentication key (`GET /users/regulad/keys`) is `ssh-rsa <base64>` with no comment field, and is the same key as the signing key and `~/.ssh/id_rsa3072.pub`. The roots' literal copies differ only in their comment fields (`regulad@github`, `regulad@github/102565467`, or none).
- **tflint's `terraform_required_version` on a module without a `terraform` block** reports on its only file when it has one, and on a made-up `terraform.tf` once it has two, which no `tflint-ignore-file` can reach: `tofu/shared` passed with `tailscale.tf` alone and failed with `ssh.tf` beside it. An empty `terraform {}` in an annotated `versions.tf` gives the rule a place to report.
