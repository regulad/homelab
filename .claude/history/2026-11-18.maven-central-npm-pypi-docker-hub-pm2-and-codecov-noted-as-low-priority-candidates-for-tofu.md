# Maven Central, npm, PyPI, Docker Hub, PM2 and Codecov noted as low-priority candidates for `tofu/` (2026-11-18)

Each could become an OpenTofu root, but none holds anything for one to track yet, so none is planned. What each offered on this date:

- **Maven Central (Sonatype's Central Portal):** no provider manages it; `kota65535/maven` only reads artifacts.
  - Namespaces and user tokens are made in the portal alone. Its Publisher API, under `https://central.sonatype.com/api/v1/publisher`, uploads and publishes deployments.
  - regulad.xyz's verification record is already `tofu/cloudflare`'s `regulad_xyz_txt_sonatype`.
- **npm:** no provider manages packages, tokens or trusted publishing.
  - `cognitedata/npm` manages an organization's members (`npm_membership`), and `mohamed-gara/npm` fetches a package's tarball.
  - Trusted publishing is set on the website or with `npm trust github|gitlab|circleci <package>` (npm CLI 11.10 and later), which asks for the account's second factor.
- **PyPI:** no provider manages it; `jeffwecan/pypi` only downloads packages.
  - Trusted publishers and API tokens are made in the web UI.
  - An API for trusted publishers is pypi/warehouse#14456, still open.
- **Docker Hub:** the official `docker/docker` provider (0.8.0) covers repositories, organizations, teams and access tokens.
  - Two-factor authentication keeps it from managing tokens, as the entry on Nexus's proxies records.
  - `tofu/dockerhub` holds only hand-issued tokens and has no state.
- **PM2 Plus (pm2.io):** the OpenTofu registry lists no provider. doppelgangerhq.com's PM2 Plus key pair was dropped and revoked on 2026-11-16.
- **Codecov:** `at-wat/ucodecov` is unofficial.
  - Its one data source, `ucodecov_settings`, reads a repository's upload token through Codecov's v2 API.
  - That token could be the source a `CODECOV_TOKEN` in `tofu/github` derives from, instead of a value kept in SOPS.
  - `tofu/github` sets no Codecov secret since PepperCord's was pruned on 2026-11-17.
