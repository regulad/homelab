# regubot signs its winget-pkgs commits with a key per pipeline (2026-11-24)

- **Not `tls_private_key`:** it keeps the private key in state, and the state bucket's versioning keeps every earlier state, so a key that a repository holds is generated outside OpenTofu, and only its public half is written in a `.tf` file.
- **A repository's SOPS file, made outside it:** `sops --config <dir>/.sops.yaml encrypt --filename-override winget.sops.yaml --input-type yaml --output-type yaml /dev/stdin`, run in `<dir>`, applies that `.sops.yaml`'s creation rules, so the file is ready to copy in beside it. The encrypted file lists each `sops.age[].recipient` in plaintext, which shows who can open it without decrypting.
- **Jenkins and the age key:** a `string` credential holds age-keygen's whole output, its two comment lines included, as the GitHub repositories' `SOPS_AGE_KEY` secrets do; sops reads that form from `SOPS_AGE_KEY`, so a job binds the credential to that variable.
