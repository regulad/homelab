# AIDE's daily check waits for Ansible runs, and amd64v3 builds count as package changes (2026-11-12)

- **Each run holds the daily check from its first play to its last.** `aide-hold.yml` runs `aide-report --run-started`, which marks `/run/aide-report/run-pending`; a check that finds the mark younger than six hours records `check-held` and exits, and `aide-report --run-ended`, the last play after the refresh, clears both and starts `aide-report.service` without waiting for it. A run cut short leaves the mark, which stops holding after six hours or at the next boot.
- **A play that calls a new option of a deployed script fails on the run that deploys it,** if it runs first: the host still has the old script. The hold's first deployment ran with `--skip-tags aide_hold`. In `--check`, `command` with `removes:` does not run, so both the hold and the release show `ok`.
- **Enabling APT's amd64v3 variant reinstalls every package that has a v3 build, at the version it had,** on the next upgrade (`Upgrade: libgpg-error0:amd64 (1.58-2, 1.58-2)` in apt's history): on orchard, 288 of 356 packages. dpkg's status gains `Architecture-Variant: amd64v3`, which `dpkg-query -f '${Architecture-Variant}'` prints; Debian 13's dpkg 1.22 prints that field empty. aide-report now keys such a package as `name=version/amd64v3`, so the move counts as a package change. A manifest from before it is compared without variants.
- **Go's telemetry mode is the first word of `<os.UserConfigDir>/go/telemetry/mode`.** A missing file means `local`, and then any `go` command writes counters under `<config>/go/telemetry/local`. A process with neither `HOME` nor `XDG_CONFIG_HOME` has no config directory and so telemetry off, as ingress's `caddy-build.service` does; its counters came from `go` run by hand as root. `GOTELEMETRY` only reports the mode. The `go_telemetry` role writes `off` for root wherever `/usr/bin/go` exists.
- **Probes leave traces unless written not to.** Loading `/usr/local/bin/aide-report` with `SourceFileLoader` writes `/usr/local/bin/__pycache__/aide-reportcpython-314.pyc` unless Python runs with `-B`. `env -i HOME=/nonexistent go version` creates `/nonexistent/.config/go/telemetry`. A probe that runs AIDE needs `LC_ALL` unset where Ansible passes a locale the host lacks: AIDE exits 20 otherwise.
