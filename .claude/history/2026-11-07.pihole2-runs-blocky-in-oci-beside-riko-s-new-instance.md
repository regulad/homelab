# pihole2 runs blocky in OCI, beside riko's new instance (2026-11-07)

- tofu/oracle created pihole2 and riko, each a VM.Standard.A1.Flex with 1 OCPU and 2 GB on Oracle Linux 10.2 (`Oracle-Linux-10.2-aarch64-2026.10.16-0`), and cut mail from 6 to 4 GB and livekit from 6 to 2 GB to make room: A1 is at 6 OCPUs and 16 GB, 2 OCPUs past Always Free. A memory change reboots the instance; both were back within two minutes, mail with 1.9 GB of 3.6 GB available. mail stays at 4 GB because clamd's reload briefly holds two signature databases.
- Created instances take their IPv6 address at launch, through `create_vnic_details.ipv6address_ipv6subnet_cidr_pair_details` with `assign_ipv6ip`, so they have no `oci_core_ipv6` or VNIC lookup of their own. `assign_private_dns_record` is create-only and must be `true` for the `pubsub` name Ansible connects to.
- alock resolves `tofu/oracle`'s hosts from the inventory's cache, which holds state for an hour: the apply that created pihole2 and riko locked and recorded only the hosts that existed before it. The next apply, after `--flush-cache`, included them.
- On a fresh Oracle Linux instance, `-e ansible_user=opc` also sets the connection of tasks delegated elsewhere, so the mail relay play's FreeIPA API calls, which run on wako, failed as unreachable. The base role, which runs earlier, had already given regulad its keys and sudo, so a rerun without the override completed.
- pihole2's blocky renders pihole's template, now `files/shared/etc/blocky/config.yml.j2`, with `blocky_upstream: tailscalerouter`; `host_files` gained `shared_src` for templates. blocky answers private-use names such as `regulad.internal`, and the reverse zones of private addresses such as `23.10.in-addr.arpa` and `80.131.10.in-addr.arpa`, with NXDOMAIN unless a conditional mapping covers them, while `100.in-addr.arpa` passes. pihole2 therefore maps pihole's nine zones, each to tailscalerouter.
- tailscalerouter's Unbound forwarded no reverse zone for the homelab ULA, so PTR lookups of homelab IPv6 addresses went to OCI's resolver and got NXDOMAIN. It now forwards `1.0.0.0.7.5.a.a.c.4.8.b.3.8.d.f.ip6.arpa.` to arawi.
- arawi answers AAAA queries for `regulad.internal` hosts from clients in its "remote" view, which takes in the tailnet and the VCN, with the ULA only. pihole's own queries also get the GUA. pihole2, through tailscalerouter, gets the remote view's answer, as tailnet clients do through split DNS.
- Under SELinux enforcing, the blocky Quadlet with host networking binds port 53; `/etc/blocky` carries `container_file_t` through a file-context rule, and the validator runs with `--security-opt label=disable`, as the new file waits in Ansible's temporary directory.
