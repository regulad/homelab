# SupIR gets no Sentry project; IzzyOnDroid's download statistics measure its use

- SupIR, which IzzyOnDroid distributes, gets no Sentry project and no SDK (Parker, 2026-11-25). IzzyOnDroid accepts Sentry or ACRA only "when they are strictly opt-in" (its APK Scans page) and otherwise marks the app with the `Tracking` anti-feature; analytics count as tracking too, so usage transactions would need the same consent. An opt-in dialog and its setting were more moving parts than SupIR's reports are worth: it is open source and reaches people only through FOSS channels, whose users tend to report issues themselves.
- Its usage figure is IzzyOnDroid's own: the yearly and monthly download counts in `https://dlstats.izzyondroid.org/iod-stats-collector/stats/basic/{yearly,monthly}/rolling.json`, keyed by package name (2,001 and 193 for `xyz.regulad.supir` on 2026-11-25), which SupIR's README shows through the shields.io badge IzzyOnDroid documents. The same applies to any other app IzzyOnDroid serves.
- Any later Sentry plan for an app IzzyOnDroid serves starts from that rule: opt-in, off by default, or the anti-feature. A build without Sentry for IzzyOnDroid alone would mean a second APK per release, since IzzyOnDroid takes the developer's own APK.
