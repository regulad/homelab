# Maintenance plays for authentik's release upgrade and its PostgreSQL major upgrade (2026-11-22)

- **authentik's releases are not evenly spaced:** quarterly in 2026 (2026.2, 2026.5, 2026.8), every two months before, so the release after the running one is read from GitHub's releases (`version/<series>.<patch>` tags, drafts and prereleases left out) rather than computed. A running container's own labels carry the image's `org.opencontainers.image.version`, the full release such as `2026.8.6`, and its `ImageName` is the tag it was started from.
- **authentik's server migrates the database as it starts,** and `/-/health/ready/` answers 200 once the database connects. CT 201 has no `curl`, so the plays check it with Ansible's `uri`.
- **PostgreSQL moves by a dump and a restore,** as the official image has no `pg_upgrade`, and a dump may skip majors. From 18 the image keeps its data under `/var/lib/postgresql/<major>/docker` and refuses a volume at `/var/lib/postgresql/data`, so the move to 18 also moves the volume's mount. The entrypoint's first initialisation answers on its socket before the real server starts, so readiness is checked over TCP, which that temporary server does not open. The database holds only `plpgsql`, and its user and database, `authentik`, come from the container's `POSTGRES_USER` and `POSTGRES_DB`.
- **Writes to `/var/backups` and `/var/lib/containers` need no `aide_writes`:** AIDE excludes both on Debian and Ubuntu.
- **A back-reference in a folded or plain YAML scalar is `'\1'`.** YAML leaves the backslash alone there, and Jinja passes `\1` to `regex_replace`; `'\\1'` reaches it as the literal text `\1`. In a double-quoted scalar, YAML takes one backslash first. A lookbehind needs no back-reference at all.
- **Check-mode runs against edited compose files exercised the decisions:** 2026.11 is refused while no 2026.11 release exists; `18-alpine` mounted at `/var/lib/postgresql` passes every check, and with the old mount is refused. The authentik cleanup found the 2026.5 and 2026.2 images left by October's stepwise upgrade.
