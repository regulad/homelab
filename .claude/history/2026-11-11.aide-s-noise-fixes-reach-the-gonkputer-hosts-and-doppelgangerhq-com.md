# AIDE's noise fixes reach the gonkputer hosts and doppelgangerhq.com (2026-11-11)

- **Checking `explain()` against a report already mailed needs the manifest from before it.** Once the relay accepts a mail, the manifest of installed packages moves with the baseline. Run later against that report, the rules that ask what changed since the baseline see that morning's upgrades as already installed: they kept vkasm's `/usr/lib/snapd/*` file-to-link swaps, and the dpkg records and `egg-info` an upgrade replaced. With each package dpkg's log shows upgraded that day put back at its earlier version, the swaps were explained. A removed path's earlier owner cannot be rebuilt that way: dpkg keeps no earlier file list.
- **The `apparmor` package ships `/var/cache/apparmor`,** so an upgrade of it puts the empty directory back. The next run of the `aide` role removes it again, which shows as one change on each host that upgraded AppArmor.
- **An apply interrupted after a task changed a unit file, but before its handlers ran, leaves the unit unreloaded.** systemd shows `NeedDaemonReload=yes`. A rerun finds the file already as declared and notifies no handler, so the reload and restart are done by hand.
- **A background apply started from a Claude Code session dies with the session.** Start a long apply detached (`setsid nohup`), writing its exit status beside its log.
- **caddy-build under its new GOPATH,** `/var/cache/caddy/go`, built in 34 seconds with an empty module cache, and left Caddy as it was because the build matched the running one.
