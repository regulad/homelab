# aboriginal is the Syncthing mesh's hub, and the tailscale role supports macOS (2026-11-18)

## The hub (syncthing_hub)

- **Split with dotfiles:** dotfiles owns everything in regulad's home and each node's Syncthing settings, aboriginal's included: the folders and their paths, `~/.claude/.stignore`, the directory modes, and usage and crash reporting. homelab owns only what is the hub's alone: its identity, its API key, lingering, the joining service and the tailnet policy.
- **Syncthing 1.29** (Ubuntu's package) keeps `config.xml`, `cert.pem` and `key.pem` in `~/.local/state/syncthing`. It lists them with `syncthing --paths`; 2.x's `syncthing paths` is refused. 2.x nodes and 1.29 sync with each other.
- **Identity:** the device ID is the base32 of the SHA-256 of `cert.pem`'s DER, so deploying the pair from SOPS keeps the ID KHV3YK5… on a rebuild. `openssl x509 -outform der | openssl dgst -sha256 -binary`, base32-encoded, checks a copy.
- **API key:**
  - `STGUIAPIKEY` (1.29's `--gui-apikey`), given through a drop-in in `/etc/systemd/user/syncthing.service.d/`, overrides the key in force.
  - `GET /rest/config/gui` returns the stored `apiKey`, and `syncthing cli` reads that one. The role sets the stored key to the SOPS one with a `PATCH` whenever they differ.
- **User units outside the home:**
  - `systemd_service` cannot query the global scope (`--global is not supported for this operation`). The role makes the `/etc/systemd/user/default.target.wants/` link with the file module instead, and `ConditionUser=` limits the unit to its user.
  - A user unit's journal is `journalctl _SYSTEMD_USER_UNIT=<unit>` as root.
  - A check run can't start or restart a unit whose file isn't written yet, so those tasks skip in check mode while the unit file is still changing.
- **A play for a new group** has no hosts until tofu/gonkputer's `ansible_host` lists the group. `ansible-playbook -i inventory -i <extra.yml>`, with a throwaway group file, check-runs it before then.

## syncthing-join

- **Waking it:** it long-polls `/rest/events?events=PendingDevicesChanged,PendingFoldersChanged` and makes a full pass on every wake. The event buffer can drop events, so an event only wakes it.
- **Restarts:** when Syncthing restarts, its long poll is cut mid-reply. `http.client.IncompleteRead` is an `HTTPException`, not a `URLError`, so it crashed the first version.
- **API details:**
  - `PATCH /rest/config/folders/<id>` replaces the devices list whole.
  - A folder the hub lacks answers 404.
  - `GET /rest/config/defaults/device` gives a new device's defaults.
- **whois:** `tailscale whois --json` works as an unprivileged user. A tagged node's owner reads as `tagged-devices`, so membership for a tagged node is its tag, `tag:syncthing`, not an owner.
- **The test:** overture, a Mac that had never run Syncthing, was accepted by the tag rule a second after its first apply. Its four folders were shared two seconds later, and the introducer brought it to winlite. aboriginal then reached it over the LAN, as local discovery found the LAN first. That is harmless: the address is checked only while a device is pending.

## Tailscale

- **Grants** take IP sets as source as well as destination (Tailscale's KB 1387). `tag:syncthing`'s grants name aboriginal by its `ipset:aboriginal--tail11540--ts--net`.
- **macOS:**
  - Homebrew's open-source `tailscaled` runs as root from the system launchd job `sh.brew.tailscale`, which `sudo brew services start tailscale` writes. Homebrew itself runs as the user.
  - `sudo` drops `/opt/homebrew/bin` from `PATH`, hence the module's `opt_dirs`.
  - `brew upgrade` doesn't restart a root service: overture ran 1.102.5 under a 1.104.2 CLI. `tailscale status` then prints a version warning before its JSON.
- **Retagging:** a joined node's tags change through `POST /api/v2/device/<node ID>/tags`, where the node ID is `tailscale status`'s `Self.ID`, without re-authenticating it. The role now retags where it used to fail.

## Tooling

- **dash:** an ad hoc `ansible -m shell` runs `/bin/sh`, which is dash on Ubuntu, so bash's `${var:0:7}` fails there.
- **`no-gua-ipv6`:** the hook matches the shape, so it flags RFC 3849's documentation prefix too. Tests use a ULA instead.
- **alock:** a tofu/gonkputer apply records every host in its inventory, so other checkouts can't apply to any of them until they contain the commit.
