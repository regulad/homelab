# kodi-plugins' publishing key in publish.sops.yaml, and /srv/kodi's files keep their modes (2026-11-18)

- **The key:** a new Ed25519 key, without a passphrase, is `ssh_key` in kodi-plugins' `publish.sops.yaml`, encrypted to Parker's age key and to kodi-plugins' own. That key's identity is the `SOPS_AGE_KEY` secret, kept in `tofu/github/secrets.sops.yaml` under `kodi_plugins`.
  - It replaced `SSH_KEY_BLOB` and `SSH_KEY_PASSPHRASE`. The old key was Parker's `regulad@winlite` key, which `kodi-publish` accepted until now.
  - The publish step decrypts the key into `SSH_KEY_BLOB` for `deploy.py` alone, and `deploy.py` takes `SSH_KEY_PASSPHRASE` as optional.
  - The `helix` branch's caller passes `secrets: inherit`, so it needed no change.
- **The host:** `SSH_KEY_HOST` is `ingress.regulad.internal`. Tailscale's resolver, `100.100.100.100`, which `deploy.py` queries, answers it with `10.23.2.31` and ingress's ULA. `tofu/github` derives it from the inventory name whose host_vars it already reads.
- **`ansible.builtin.file` with `recurse`:** the mode applies to every file in the tree, not only to directories. `/srv/kodi`'s `0755` made each publish's 0644 files executable at the next `host_files` run, which therefore never reported `changed=0`. The symbolic `u=rwX,go=rX` keeps directories searchable and leaves files as written.
- **Check mode and symlinks:** check mode reports a recursed tree as changed whenever it holds a symlink, here `/srv/kodi/helix`. It compares the link's own mode, 0777, with the desired one. A real run cannot chmod a symlink on Linux and reports no change, so only a second real run shows the tree settled.
