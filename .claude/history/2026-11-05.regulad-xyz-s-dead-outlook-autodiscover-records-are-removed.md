# regulad.xyz's dead Outlook Autodiscover records are removed (2026-11-05)

- regulad.xyz's `autodiscover` CNAME and `_autodiscover._tcp` SRV sent Outlook to `mail.regulad.xyz:443`, where nothing listens, so each Outlook setup waited for them to time out before trying its other methods. They are deleted, not replaced with a Worker serving Autodiscover.
- Outlook POSTs its Autodiscover request to `https://<domain>/autodiscover/autodiscover.xml`, then `https://autodiscover.<domain>/…`, and a plain-XML response can describe an IMAP and SMTP account in `<Protocol>` blocks. mailcow's documentation says only Outlook 2019 and earlier use it for such an account: Outlook 2021, Microsoft 365's Outlook and the new Outlook need the settings entered by hand.
